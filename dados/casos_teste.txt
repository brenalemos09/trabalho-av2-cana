CASOS DE TESTE - TRABALHO AV2 CANA

========================================
1. SUBARRANJO MÁXIMO
========================================

Caso 1 - Caso comum
Entrada:
[-2, 4, -1, 3, -5]

Saída esperada:
Soma máxima: 6
Índice inicial: 1
Índice final: 3


Caso 2 - Somente números negativos
Entrada:
[-8, -3, -6, -2, -5, -4]

Saída esperada:
Soma máxima: -2
Índice inicial: 3
Índice final: 3


Caso 3 - Vetor de tamanho 1 positivo
Entrada:
[7]

Saída esperada:
Soma máxima: 7
Índice inicial: 0
Índice final: 0


Caso 4 - Vetor de tamanho 1 negativo
Entrada:
[-5]

Saída esperada:
Soma máxima: -5
Índice inicial: 0
Índice final: 0


Caso 5 - Empate de soma
Entrada:
[2, -2, 2]

Saída esperada:
Soma máxima: 2
Índice inicial: 0
Índice final: 0


Caso 6 - Todos positivos
Entrada:
[1, 2, 3, 4]

Saída esperada:
Soma máxima: 10
Índice inicial: 0
Índice final: 3


Caso 7 - Valores mistos
Entrada:
[-4, 2, 3, -2, 3, -7]

Saída esperada:
Soma máxima: 6
Índice inicial: 1
Índice final: 4


Caso 8 - Melhor intervalo no início
Entrada:
[5, 4, -10, 2]

Saída esperada:
Soma máxima: 9
Índice inicial: 0
Índice final: 1


Caso 9 - Melhor intervalo no final
Entrada:
[-10, 1, -5, 6, 4]

Saída esperada:
Soma máxima: 10
Índice inicial: 3
Índice final: 4


Caso 10 - Vetor com zero
Entrada:
[0]

Saída esperada:
Soma máxima: 0
Índice inicial: 0
Índice final: 0


Regra usada em caso de empate:
É escolhido o menor intervalo. Se o tamanho também for igual,
é escolhido o intervalo que começa primeiro.
